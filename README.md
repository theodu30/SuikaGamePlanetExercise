# Suika Game Planet
This project is an attempt at recreating Suika Game Planet by Aladdin X Inc.  
It was done in 3.5 hours as a class exercise.  

## Features
This project includes all 11 fruits from cherry to watermelon.  
You launch fruits in orbit in a gravity field.  
Each launched fruit varies between the first 5.  
When 2 similar fruits collide, they fuse into a fruit of the next tier.  
If it's 2 watermelons, they are both destroyed.  
You gain points with each fusion scaling with fruit size,  
and you gain extra for fusing two watermelons.  
The only way to fail is if a fruit exits orbit.  
Bigger fruits are heavier so it's more difficult to move them  
around with smaller fruits.

## Limitations
There is no indication whatsoever on the screen to give you an idea  
of what fusion stage you're at.  
There is no high score in this project.

## Known Issues
You can, in extreme cases, make fruits go out of orbit without  
triggering the loss condition (spawn a fruit in another  
one that is halfway out of the gravity field).
